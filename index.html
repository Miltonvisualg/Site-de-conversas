Como publicar de graça 1. Crie uma conta gratuita em github.com pelo Chrome. 2. Crie um repositório novo, por exemplo site-conversas, marcado como público. 3. Envie o arquivo index.html para ele. 4. Em Settings, depois Pages, escolha a branch main e salve. 5. Em um ou dois minutos o site estará no ar num endereço do GitHub Pages.
